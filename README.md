# 🚀 Cognifyz SD Internship Tasks

This repository contains a series of tasks assigned by **Cognifyz Technologies** as part of the **Software Development Internship** application process.
The tasks cover various programming and development concepts aimed at enhancing skills in **problem-solving, web scraping, file I/O, and CRUD operations**.

---

## 📚 Tasks Overview

### 🎮 Simple Game Using Conditional Statements
A basic **text-based game** built using conditional logic to manage game flow and player interactions.

### 🔢 Number Pattern Generator
A program to generate **simple number patterns** using loops to control structure and output design.

### 📂 CRUD Application with File I/O
A **task management application** that allows users to:
- Create tasks ✍️
- Read tasks 📖
- Update tasks ✏️
- Delete tasks ❌

Persistent storage is achieved with **File I/O** to save and load tasks.

### 🌡️ Temperature Converter
A **console-based application** that converts temperatures between **Celsius ↔ Fahrenheit** with interactive user input.

### 🌐 Interactive Web Scraping Program
A **web scraping tool** that fetches data from websites, processes it, and displays results in a structured format.

## 💻 How to Run

1.  **Clone the repository:**
    ```
    git clone https://github.com/demon-codly/cognifyz_SD-Intern.git
    ```
2.  Open the project folder in your preferred IDE (e.g., VS Code, PyCharm).
3.  Run the Python file for the specific program you want to test:
    ```
    python "text-based game.py"
    ```
